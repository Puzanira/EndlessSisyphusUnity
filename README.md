# Бесконечный Сизиф

Unity-порт браузерной игры «Бесконечный Сизиф»: процедурный пиксель-арт,
физика подъёма валуна, погода, сезоны и процедурный звук.

## Требования

- Unity `6000.5.3f1` (подойдут близкие версии Unity 6)
- Рендер-конвейер — **URP (Universal Render Pipeline) 2D**. Пакет
  `com.unity.render-pipelines.universal` подтягивается автоматически из
  `Packages/manifest.json`; URP-ассеты уже назначены в Graphics/Quality Settings.
- Проект не требует сторонних ассетов или ручной настройки сцены

## Как запустить

Проект проверен в **Unity 6000.5.3f1**.

1. Клонируйте репозиторий или скачайте его через **Code → Download ZIP**.
2. В Unity Hub нажмите **Add → Add project from disk** и выберите корневую
   папку `EndlessSisyphusUnity`.
3. Дождитесь окончания импорта пакетов и компиляции скриптов.
4. Откройте сцену
   `Assets/EndlessSisyphus/Scenes/Main.unity`.
5. Нажмите **Play**.

Сцена включена в **File → Build Profiles → Scene List**. Она намеренно пустая:
`Bootstrap.cs` при запуске создаёт камеру, игру и интерфейс автоматически.

## Управление

Ввод идёт через пакет [`arcade-controls`](https://github.com/Puzanira/arcade-controls)
(логические контролы автомата). Без железа работает клавиатурная симуляция пакета —
клавиши в скобках берутся из его конфига:

- **Крутилка** (колесо мыши) — толкать камень: вращение динамо даёт усилие. Крути
  ровно, без рывков; в ветер сам перестань крутить.
- **Кнопка «!»** (зажать; клавиша **3**) — усиленный режим для крутого склона.
- **Красная кнопка** (нажать; клавиша **1**) — вкл/выкл защитный режим во время дождя
  (тоггл): нажми, чтобы толкать камень под дождём, продолжая крутить; после дождя нажми
  ещё раз, чтобы выключить.
- **Зелёная кнопка** (нажать; клавиша **2**) — интерфейс: начать игру, подтвердить,
  начать заново.
- **Menu** (**Esc**) — свернуть игру (корректный выход из партии).

Подробнее об устройстве игры и замене процедурного арта:
[`Assets/EndlessSisyphus/README.md`](Assets/EndlessSisyphus/README.md).

## Структура репозитория

- `Assets/EndlessSisyphus/` — исходный код игры
- `Assets/EndlessSisyphus/Scenes/Main.unity` — стартовая сцена
- `Packages/` — зависимости Unity
- `ProjectSettings/` — настройки проекта и версия редактора

Сгенерированные Unity-папки (`Library`, `Temp`, `Logs`, `UserSettings`) в Git не
добавляются.
